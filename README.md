# To-Do List App

A simple command-line To-Do List application built using Python.

## Features

- Add new tasks
- View pending tasks
- Mark tasks as completed
- View completed tasks separately
- Save tasks using JSON file storage
- Handle invalid task-number inputs
- Preserve tasks after restarting the application

## Technologies Used

- Python
- JSON
- File Handling
- Exception Handling

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python todo.py
```

## Project Structure

- `todo.py` — Main application
- `tasks.json` — Local file used to store tasks (created when the app saves data)
